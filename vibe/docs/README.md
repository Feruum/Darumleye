# Darumleye / Spec Review — документация

**Актуальность: 27 ноября 2026 (Asia/Almaty).** Darumleye — статическая проверка требований до разработки и тестирования для [BCC-HUB × MNU FinTech Hackathon](https://github.com/BCC-HUB/ai-requirements-validator-task). [Главный README проекта](https://github.com/Feruum/Darumleye/blob/main/README.md) содержит демонстрацию, запуск и итог. CLI без дополнительных регламентов работает без Docker и БД; веб-приложение использует локальный React/Vite, Bun/Hono, FastAPI, PostgreSQL и Chroma.
