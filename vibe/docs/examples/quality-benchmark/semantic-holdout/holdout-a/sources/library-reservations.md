# Фрагмент ТЗ: резервирование печатных книг для выдачи в городской библиотеке

Раздел описывает создание резерва, очередь, подготовку экземпляра и получение книги читателем. Интеграция с каталогом и оформление читательских билетов описаны отдельно. Система ведет издания и физические экземпляры, не приравнивая резерв к фактической выдаче. В правилах создания резерва подразумевается соблюдение остальных применимых условий, если ими не установлен иной результат.

## Правила

- **LIB-01**. Издание имеет единый каталожный идентификатор. Каждый физический экземпляр этого издания имеет собственный уникальный штрихкод; при выдаче в резерв записывается штрихкод переданного экземпляра.
- **LIB-02**. Один читатель может иметь одновременно не более трех активных резервов в статусах «В очереди» и «К выдаче». Запросы к электронным книгам не считаются резервами физических экземпляров и в этот лимит не включаются.
- **LIB-03**. Новый резерв запрещается для любого читателя, у которого есть хотя бы один просроченный возврат, независимо от категории читательского билета; в том числе это ограничение распространяется на льготные билеты.
- **LIB-04**. Читатель с действующим льготным билетом и просроченным возвратом при соблюдении остальных условий должен получить новый резерв; его запрос нельзя отклонять по причине просроченного возврата.
- **LIB-05**. Срок удержания экземпляра составляет 72 часа с момента перехода резерва в статус «К выдаче». Расчет срока ведется по абсолютному UTC-времени, а в интерфейсе момент окончания показывается в часовом поясе отделения.
- **LIB-06**. Сотрудник может выдать экземпляр, пока с момента перехода резерва в статус «К выдаче» прошло не более 72 часов, в том числе ровно 72 часа.
- **LIB-07**. Резерв автоматически считается истекшим с момента, когда с перехода в статус «К выдаче» прошло 72 часа или больше: фактическая выдача по нему запрещена независимо от времени запуска фонового задания.
- **LIB-08**. Для очереди по изданию приоритет определяется исключительно временем поступления резервов, которое фиксируется с точностью до секунды; одинаковое время дает одинаковый приоритет. Если доступен один экземпляр, система должна автоматически и воспроизводимо выбрать ровно одну заявку с наивысшим приоритетом.
- **LIB-09**. Если при подготовке резерва экземпляр признан поврежденным, обработка должна автоматически завершиться определением итогового статуса резерва и уведомлением читателя. При наличии другого свободного экземпляра того же издания в данном отделении резерв переводится на этот экземпляр с сохранением статуса «К выдаче».
- **LIB-10**. Уведомление о готовности экземпляра должно быть отправлено с настолько небольшой задержкой, чтобы читатель не ощутил неудобства из-за ожидания уведомления.
- **LIB-11**. В личном кабинете читатель видит только свое место в очереди и ее общую длину. Сотруднику отделения доступен служебный список очереди с идентификаторами билетов, доступ к которому у читателя отсутствует.
- **LIB-12**. Читатель может отменить свой резерв в статусах «В очереди» и «К выдаче». Если экземпляр уже передан и резерв в статусе «Выдано», прекращение пользования оформляется возвратом книги, а не отменой резерва.
- **LIB-13**. Один читатель может иметь не более одного активного резерва на конкретное издание, даже если экземпляров несколько. Разные издания одного произведения считаются разными единицами для этого ограничения.
- **LIB-14**. При выдаче сотрудник сверяет номер действующего читательского билета: номер можно считать с пластиковой карты или получить из QR-кода цифрового билета, оба способа дают тот же идентификатор.
- **LIB-15**. Читатель младше 14 лет получает детское издание лично; выдача из изданий с маркировкой 14+ разрешается с дня четырнадцатилетия включительно. Возраст проверяется по календарной дате визита.
- **LIB-16**. В правилах формирования отчета датой выдачи является календарная дата фактической передачи экземпляра, а датой возврата — календарная дата фактического приема обратно; дата создания резерва не заменяет ни одну из этих дат.
