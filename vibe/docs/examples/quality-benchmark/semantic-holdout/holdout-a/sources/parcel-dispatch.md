# Фрагмент ТЗ: распределение отправлений в сервисе городской курьерской доставки

Раздел описывает прием стандартных отправлений, распределение между курьерами, доставку и отображение ее результатов. Время здесь указано по Asia/Almaty, а рабочие дни определяет единый производственный календарь сервиса. Расчет тарифов, обработка претензий и расчетного листа курьера находятся вне этого раздела. В правилах приема и назначения подразумевается соблюдение остальных применимых условий, если не указан иной результат.

## Правила

- **PAR-01**. Стандартное отправление принимается при массе от 0,2 кг до 15,0 кг включительно и длине каждой стороны не более 60 см; масса фиксируется с точностью до 0,1 кг.
- **PAR-02**. При регистрации стандартного отправления с массой 15,0 кг и более оператор должен получить однозначный отказ в приеме; зарегистрировать накладную по запросу с такой массой нельзя.
- **PAR-03**. Адрес и контактный телефон получателя указываются в накладной при приеме. После вручения редактирование адреса запрещено; исправление адреса до вручения допускается диспетчером с сохранением предыдущего значения в истории.
- **PAR-04**. Распределение принятых отправлений запускается ежедневно в 19:00. Цикл распределения должен автоматически завершаться ровно одним результатом для каждого отправления: «Курьер назначен», «Перенесено на следующий день» или «Отказ в доставке».
- **PAR-05**. Если к моменту распределения доступен хотя бы один курьер, выбирается курьер с самым ранним временем доступности; при равенстве времени выбирается меньший числовой идентификатор курьера. Для отправления при этом устанавливается результат «Курьер назначен».
- **PAR-06**. Курьер считается доступным, если его смена целиком покрывает обещанный интервал вручения, зона включает адрес получателя, а остаток его грузоподъемности не меньше массы отправления.
- **PAR-07**. После второй неудачной попытки вручения стандартное отправление автоматически переводится в статус «Возврат отправителю». Новые попытки вручения по такому отправлению больше не назначаются.
- **PAR-08**. Для каждого стандартного отправления, по которому зарегистрированы две неудачные попытки вручения, система обязана назначить третью попытку на следующий рабочий день до начала возврата отправителю.
- **PAR-09**. Неудачной попыткой считается зафиксированное прибытие курьера по адресу без вручения из-за отсутствия получателя. Отмена визита получателем до выезда курьера и перенос по инициативе диспетчера в число таких попыток не входят.
- **PAR-10**. Список завершенных доставок в панели диспетчера при выборе фильтра «За сегодня» содержит задания, относящиеся к текущему календарному дню. В списке выводятся отдельно плановая дата доставки и дата фактического вручения; при запоздалой доставке они могут различаться.
- **PAR-11**. Изменения состояния отправления должны появляться на странице отслеживания с такой задержкой, чтобы информация воспринималась получателем как актуальная.
- **PAR-12**. Для сотрудника-диспетчера в карточке отправления показывается полный контактный телефон получателя. На доступной получателю странице отслеживания номер показывается только в маскированном виде с четырьмя последними цифрами.
- **PAR-13**. Получатель может подтвердить вручение одноразовым кодом вместо подписи на терминале курьера. Только один из этих двух способов достаточен для оформления вручения; одновременное подтверждение обоими способами не требуется.
- **PAR-14**. Обещанный клиенту интервал 09:00–12:00 включает момент 09:00 и момент 12:00. Посылка считается врученной вовремя при регистрации факта вручения в любом из этих моментов или между ними.
- **PAR-15**. Если диспетчер до выезда курьера по просьбе получателя изменил адрес на находящийся вне зоны текущего курьера, система снимает текущее назначение и направляет отправление на перераспределение; само отправление не отменяется.
- **PAR-16**. В истории операций хранится точное серверное время изменения состояния с точностью до секунды; в клиентской ленте то же время отображается с точностью до минуты посредством отбрасывания секунд.
- **PAR-17**. После успешного вручения код отслеживания остается прежним; новый код формируется только для нового физического отправления после повторной регистрации, а не при изменении статуса ранее зарегистрированного отправления.
