# Прием и проверка письменных заданий на университетских курсах

Модуль предназначен для сдачи файлов домашних письменных работ в течение семестра и их проверки по критериям преподавателя. Проведение экзаменов, наблюдение за студентами и ведение общей академической ведомости не входят в модуль.

R01. Преподаватель создает задание для выбранного курса, указывает название, текст задания и точный срок сдачи с датой и временем по московскому часовому поясу. Доступ к заданию получают только студенты, внесенные в список курса, и назначенные преподаватели.
R02. В качестве работы принимается один файл PDF или DOCX объемом не более 20 Мбайт. При сдаче другого формата, превышении размера или отправке пустого файла сервис отклоняет загрузку и показывает причину; ссылки вместо файлов не принимаются.
R03. До завершения разрешенного срока сдачи студент может заменить файл. Сервис хранит время регистрации каждой принятой версии и содержание всех принятых файлов, однако преподавателю в обычной проверке доступна только последняя принятая версия.
R04. Студенту разрешается сдавать и заменять файл еще в течение 48 часов после указанного преподавателем срока. Версия, принятая позже этого срока, автоматически помечается как просроченная; по истечении дополнительного периода сдача окончательно прекращается.
R05. При наступлении указанного преподавателем срока сервис блокирует форму загрузки задания для всех студентов. Новые версии после этого момента через форму и серверный интерфейс приема файлов не регистрируются.
R06. Индивидуальное изменение срока сдачи преподавателем не предусмотрено: установленный срок и дополнительный период одинаковы для всех студентов курса.
R07. При проверке письменной работы используется стандартная рубрика из трех критериев: содержание — от 0 до 60 целых баллов, структура — от 0 до 25 целых баллов, оформление — от 0 до 20 целых баллов. Каждый критерий может быть оценен независимым максимальным баллом.
R08. Итоговая оценка каждого проверяющего выражается целым числом от 0 до 100 и равна сумме выставленных им трех баллов без округления, пересчета, ограничения максимума или изменения баллов отдельных критериев.
R09. Для задания с двойной проверкой назначаются два проверяющих, которые не видят оценки друг друга до сдачи своих заключений. Если разница итоговых оценок не превышает 15 баллов, окончательная оценка равна их среднему с округлением половины вверх. При большей разнице назначается третий проверяющий; опубликование окончательной оценки допускается только после его заключения.
R10. Проверяющий может сохранять текстовый отзыв и выставленные баллы как черновик. Студент видит только окончательно опубликованные отзыв и оценку; черновик и история правок остаются недоступны студенту.
R11. Если преподаватель включил взаимную проверку, сервис показывает назначенному студенту файл работы другого участника под случайным кодом. До окончания взаимной проверки сервис не раскрывает этому проверяющему имя, фамилию, электронный адрес и группу автора. Внутреннее содержание загруженного файла при этом сохраняется неизменным.
R12. Для удобства взаимной проверки студент может скачать таблицу назначенных ему работ с кодом, ссылкой на файл, фамилией автора и номером учебной группы автора. Эта таблица доступна в течение всего периода взаимной проверки.
R13. Список участников курса поступает из университетского справочника в виде имени, фамилии и университетского электронного адреса каждого студента. Для связывания пользователя со строкой списка модуль использует этот адрес; иных идентификаторов справочник не предоставляет.
R14. После публикации окончательной оценки модуль передает результат в университетскую ведомость. Принимающая сторона требует обязательные поля: персональный номер студента из учетной системы университета, код курса, код задания и целую окончательную оценку. Передать результат вместо персонального номера по электронной почте ведомость не позволяет.
R15. Список представленных работ у преподавателя должен открываться без ощутимой задержки даже для курса с 300 принятыми работами и прикрепленными файлами максимального разрешенного размера.
R16. Письмо студенту о появлении результата отправляется только после публикации окончательной оценки. Отдельные письма при сохранении черновика проверяющего, добавлении промежуточного заключения и повторной загрузке файла не отправляются.
