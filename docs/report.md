## Критические дефекты

Блокирующие замечания критического и высокого приоритета. Счётчик критических нарушений в сводке учитывает только уровень Critical.
- D-001 (Критическая): Контракт дочернего API не позволяет однозначно реализовать чтение настроек: родительский документ требует чтения через этот API, тогда как дочерняя спецификация обозначает метод как GET, но задаёт URL saveLimit и описывает замену настройки. Неясно, должен ли этот вызов читать или изменять настройки.
